If you cannot open Pixel's web dashboard on an iPhone or iPad, the issue is usually related to Safari settings or content blockers. Follow the steps below to restore access.

<Steps>
  <Step title="Use Safari">
    Pixel's dashboard is tested and supported in Safari on iOS. If you are using another browser, switch to Safari first.
  </Step>
  <Step title="Disable Content Blockers">
    Open **Settings > Safari > Extensions** and turn off any content blockers or ad blockers. These extensions can interfere with the dashboard's scripts and styles.
  </Step>
  <Step title="Setup JavaScript">
    In **Settings > Safari > Advanced**, make sure **JavaScript** is toggled on. The dashboard requires JavaScript to load configuration panels and save changes.
  </Step>
  <Step title="Clear Cache and Data">
    Go to **Settings > Safari > Clear History and Website Data**, then confirm. This removes cached files that may be outdated or corrupted.
  </Step>
  <Step title="Reload the Dashboard">
    Close Safari completely, reopen it, and navigate back to the Pixel dashboard URL. Log in again if prompted.
  </Step>
</Steps>

<Tip>
  If the dashboard still fails to load after these steps, try setup Private Browsing mode to rule out extension conflicts.
</Tip>
