Block coordinated raids and low-effort spam accounts before they can post.

## Overview

### Why use antiraid?

Raids usually arrive as a flood of freshly created accounts joining together, often still using Discord's default avatar. Antiraid punishes those accounts automatically so your moderators are not overwhelmed.

### How does antiraid work?

Each antiraid module watches a specific pattern: mass joins, account age, or default avatars. When the pattern is detected, Pixel applies the configured punishment.

All antiraid commands require the **administrator** permission.

---

## Configuring antiraid

### Setup antiraid on your server

Run the initial setup once. It creates the required configuration entry so modules can be setup.

```js
,antiraid setup
```

### Setting the logs channel

Send every antiraid event to a dedicated channel so you can audit later.

<CodeGroup>

```js Syntax
,antiraid logs (channel)
```

```js Example
,antiraid logs #antiraid-logs
```

</CodeGroup>

### Whitelisting an expected joiner

Create a one-time bypass for a user you know is about to join.

<CodeGroup>

```js Syntax
,antiraid whitelist (user)
```

```js Example
,antiraid whitelist @jonathan
```

</CodeGroup>

## Available modules

### Mass join protection

Trigger a punishment when too many members join in a short window.

<CodeGroup>

```js Syntax
,antiraid massjoin setup (punishment) (threshold)
```

```js Example
,antiraid massjoin setup ban 5
```

</CodeGroup>

You can also change the threshold or punishment later without disabling the module.

```js
,antiraid massjoin threshold 10
,antiraid massjoin punishment kick
```

### New account protection

Punish accounts younger than the configured age when they join.

<CodeGroup>

```js Syntax
,antiraid age setup (time) (punishment)
```

```js Example
,antiraid age setup 7d ban
```

</CodeGroup>

### Default avatar protection

Punish accounts still using Discord's default avatar.

<CodeGroup>

```js Syntax
,antiraid avatar setup (punishment)
```

```js Example
,antiraid avatar setup kick
```

</CodeGroup>

---

## Disabling an antiraid module

Every module has a matching `disable` subcommand.

<CodeGroup>

```js Syntax
,antiraid (module) disable
```

```js Example
,antiraid massjoin disable
```

</CodeGroup>

---

## Viewing the antiraid configuration

Use `antiraid config` to see setup modules and their settings.

```js
,antiraid config
```

Use `antiraid whitelisted` to see every active whitelist entry.

```js
,antiraid whitelisted
```
