Pixel's antinuke channel creation module watches for members creating too many channels in a short period. Attackers use channel spam to bury important channels, confuse members, or distract admins during a raid.

## Usage

```text
,antinuke channelcreate enable <threshold> <punishment>
,antinuke channelcreate disable
,antinuke channelcreate settings
```

## Parameters

| Name | Description |
| --- | --- |
| `threshold` | Number of channel creations allowed before triggering |
| `punishment` | Action applied to the offender (see [Punishments](/resources/punishments)) |

## Example

```text
,antinuke channelcreate enable 3 strip
```

The 4th channel creation strips the offender's dangerous permissions.

<Tip>
  Pair with [Channel deletion](/security/antinuke/channeldelete) so both sides of channel abuse are covered.
</Tip>
