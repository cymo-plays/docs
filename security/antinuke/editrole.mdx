---

Pixel's antinuke role editing module watches for permission changes that could escalate a member's access. Attackers often edit an existing role to grant themselves Administrator or Manage Server rather than creating a new one.

## Usage

```js
,antinuke editrole setup <punishment>
,antinuke editrole disable
,antinuke editrole settings
```

## Parameters

| Name | Description |
| --- | --- |
| `punishment` | Action applied when a role's dangerous permissions are edited (see [Punishments](/resources/punishments)) |

## Example

```js
,antinuke editrole setup ban
```

Any edit that adds a dangerous permission to a role results in an immediate ban for the offender.

<Note>
  This module fires on the first offending edit. There is no threshold parameter.
</Note>
