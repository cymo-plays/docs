Pixel's antinuke role creation module watches for members creating too many roles in a short period. Attackers sometimes flood a server with roles to hide their tracks or prep for a raid. This module stops them at the threshold you set.

## Usage

```text
,antinuke rolecreate enable <threshold> <punishment>
,antinuke rolecreate disable
,antinuke rolecreate settings
```

## Parameters

| Name | Description |
| --- | --- |
| `threshold` | Number of role creations allowed before triggering |
| `punishment` | Action applied to the offender (see [Punishments](/resources/punishments)) |

## Example

```text
,antinuke rolecreate enable 3 strip
```

This lets a user create up to 3 roles. On the 4th creation, Pixel strips their dangerous permissions.

<Tip>
  Combine with [Role deletion](/security/antinuke/roledelete) so both directions are covered.
</Tip>
