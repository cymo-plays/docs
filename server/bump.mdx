Pixel can remind your server when it is time to bump on Disboard or Disforge. This helps keep your server visible in listing directories without relying on someone to remember the schedule. This page covers how to enable reminders, set the reminder channel, and customize the message.

## Enable bump reminders

Turn on reminders for your server:

```text
,bumpreminder enable
```

Pixel will start watching for bump commands and notify you when the cooldown expires.

## Set the reminder channel

Choose where Pixel should post bump reminders:

```text
,bumpreminder channel #bump-reminders
```

Make sure the channel is visible to the members you want to handle bumps.

## Customize the reminder message

Write a custom script that Pixel will post when the bump is ready:

```text
,bumpreminder message @here It is time to bump the server! Use `!d bump` or `!disforge bump`.
```

You can use plain text or Pixel script variables to mention roles, include the server name, or add embed formatting.

## How it works

Pixel detects when a valid bump command is used in your server. It calculates the platform cooldown, then posts your reminder message in the configured channel once the cooldown is over. If you bump early, Pixel adjusts the timer automatically.

<Note>
  Bump reminders only work if the bump bot is present and active in your server. Pixel does not send the bump itself, it only reminds you when it is time.
</Note>
