Look up Fortnite items, the shop, and player stats without leaving Discord.

## Overview

Pixel's Fortnite integration pulls live data from the Fortnite API. Anyone in your server can use these commands; no account linking required.

---

## Item lookup

Search for a Fortnite cosmetic by name.

<CodeGroup>

```js Syntax
,fortnite item (cosmetic)
```

```js Example
,fortnite item Renegade Raider
```

</CodeGroup>

---

## Item shop

Show the current daily shop rotation.

```js
,fortnite shop
```

---

## Player stats

### Lifetime stats

Look up a player's lifetime statistics by Epic username.

<CodeGroup>

```js Syntax
,fortnite lifetime (username)
```

```js Example
,fortnite lifetime Ninja
```

</CodeGroup>

### Season stats

Look up a player's current season statistics.

<CodeGroup>

```js Syntax
,fortnite season (username)
```

```js Example
,fortnite season Ninja
```

</CodeGroup>
