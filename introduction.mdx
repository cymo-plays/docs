This documentation covers everything from anti-nuke protection and moderation to tickets, VoiceMaster, Last.fm integration, and the full economy system. Whether you are setting Pixel up for the first time or looking for a specific feature guide, you will find step-by-step instructions and command references here.

## Get started in three steps

<Steps>
  <Step title="Invite Pixel">
    Add Pixel to your server with the invite link and grant the requested permissions so it can manage channels, roles, and messages.
  </Step>
  <Step title="Run setup">
    In your server, type `,setup` to launch Pixel's guided configuration. This creates default settings for moderation logging, welcome messages, and basic auto-moderation.
  </Step>
  <Step title="Configure features">
    Use the dashboard or run commands to turn on anti-nuke, VoiceMaster, tickets, reaction roles, and any other modules you need.
  </Step>
</Steps>
